# Integration boundaries

The stable side of every integration is a cairn contract (engine protocol, operator
schema, connection kind); the moving side is the vendor's. Vendor docs are not repeated.

| Integration | Cairn owns | Backend owns | Cairn contract | Failure boundary | Status |
|---|---|---|---|---|---|
| **MLflow** (registry + tracking) | when to register/promote (a leg after the human gate), the tags it stamps, the run's `report_to`/`tracking_*` knobs, the `MLFLOW_TRACKING_URI` deploy check (`src/cairn/core/deploy_check.py:393-406`) | model versions, aliases, experiment storage | operators `model/register`, `model/card`, `model/baseline` (`cairn/operators/official/model_registry/`); trainer `report_to: [mlflow]` (`operator_training/train_entry.py`) | MLflow down → the register leg fails; training continues without tracking only if `report_to` omits it | integration-tested with a local MLflow (pack tests); registry tags/aliases target #2196 |
| **Metaflow** (execution substrate) | the engine adapter behind `DataflowEngine`, engine selection by profile, secrets scoping (ADR-0089 D3), the single-step `CairnFlow` bridge | scheduling (`@kubernetes`/`@batch`), `@resources`/`@retry` inside the flow, datastore, metadata service | `cairn.dataflow_engines: metaflow` (`operator_dataflow/engines_metaflow.py`); profile keys `metaflow_metadata_root`, `metaflow_datastore(_root)` | submit/poll/cancel through the engine protocol; re-attach by pathspec; cancel kills the process group (#1348) | conformance + bridge tests in the dataflow pack (skip without the extra); golden path proven locally through Metaflow |
| **SkyPilot** (provisioning) | the door (`src/cairn/core/dataflow/engine_door.py` (the flow-engine door, ADR-0134 D3c; SkyPilot answers through its `check_ready()`)), cost estimate and gate before `sky launch`, teardown on cancel, receipts | clusters, cloud credentials, spot handling | `cairn.dataflow_engines: skypilot` (`operator_dataflow_skypilot/factory.py`, `cairndev[skypilot]`); `CAIRN_SKYPILOT_USE_SPOT` | no preemption recovery today (GAP, #2192) | engine tests exist (`test_skypilot_engine.py`); not production-proven |
| **vLLM** (serving) | serve/stop lifecycle as legs (`serve/start`, `serve/stop`, `serve/vllm`), endpoint record, batch/bench operators (`infer/batch`, `infer/bench`) | the server process, adapters loaded, throughput | `cairn/operators/official/serving/` (ADR-0098) | reachability checks (`test_serve_reachability.py`); a failed serve leg fails the pipeline | code-complete; live halves deferred (ADR-0098 §8); champion/challenger is #1628 |
| **Object storage (S3)** | artifact relay to `durable_uri` (`src/cairn/core/storage/artifact_bytes.py`), checkpoint mirror (`checkpoint_sync.py`), capture index | the bucket | `CAIRN_ARTIFACT_S3_BUCKET`/`_PREFIX`, `CAIRN_CHECKPOINT_BUCKET` | relay is best effort; checkpoint sync is a silent no-op when unset (GAP, #2191) | used on prod for artifacts; checkpoints unverified |
| **Databases** | the store contracts and migrations (`src/cairn/core/storage/{sqlite,postgres}`, `migrations.py`) | the server | `CAIRN_STORAGE` selector | twins must stay in step (CI suite runs sqlite; postgres in the deploy matrix) | sqlite CI-tested; postgres production |
| **Compute providers** (`train/runpod|vast|modal|kaggle`, `compute.ssh`) | the `remote_job` protocol (submit/poll/cancel), job channel, `compute/acquire|release` with a lease sweep (ADR-0097; the two operators ship with cairn-platform today and move into the public `cairn-operator-remote` pack per ADR-0151 D6; `cairn compute status|sweep` is public), image pinning | the machine | operator schemas in `operator_training`/`operator_compute`; connections | provider polling timeouts → leg fails; lease sweep releases | ssh path production-proven (2026-08-28 campaign); providers integration-tested with mocked transports |
| **Durable runtimes** (DBOS, Temporal) | which runtime runs agentic graphs, activities for pipeline legs (`runtime/temporal/pipeline_activities.py`) | durability/history | `CAIRN_RUNTIME` | a worker/server image mismatch is a real failure mode (#2172; runbook) | Temporal profile is prod's; DBOS in the deploy matrix |
| **Secrets** (Infisical, env) | the builtin `secrets/env`, `secrets/infisical` operators (capability `secrets.store`, bound per profile) and connection kinds; never in the spec | the vault | connections | missing secret → refused at the door / operator error | Infisical pack tested |
| **LLM providers** | one gateway (`build_chat_model`) with redaction + budget | the API | `services/llm` | provider errors surface as run failures with cost recorded | — |
| **Hugging Face Hub** | `artifact_target: hf` for adapters, gated-model licence door (`src/cairn/core/model_license_gate.py:95`) | the repo | trainer knobs | licence not accepted → refused before the run | used on the prod campaign |
| **transformers + peft** (CPU LoRA, `cairn-operator-train-local`) | the `train.finetune` contract, the loop (seed, batches, held-out loss), where the adapter lands, the stage's `model` descriptor | model loading, the LoRA layers, hub downloads of `base_model` | `train.finetune/1.0.0`; the `[train]` extra (`torch>=2.11,<2.12`, `transformers>=5.5,<5.6`, `peft>=0.20,<0.21`, `datasets>=4.3,<4.4`) | extra absent → refused at run naming it; hub unreachable → the leg fails loading `base_model`; non-finite loss → refused before saving | a one-layer GPT-2 in the pack's `-m train` tests; not in the engine image (ADR-0127 D4) |

# Core concepts (glossary)

Definitions are taken from code docstrings and ADRs, not invented. Tags: OBSERVED unless
stated. "Public" = intended for pack/operator authors or API clients.

| Concept | Meaning | Defined in | Owned by | Consumed by | Public? | Related |
|---|---|---|---|---|---|---|
| **Run** | the governed unit: one admitted execution with identity (`template_ref` stamped at admission, ADR-0084 D0), workspace, inputs, cost, status, events. | **Pipeline** | the pack's top orchestrator: `pipelines/*.yaml`, a DAG of legs with `inputs`, `governance` (budget, series, approvers), `on:`/`triggers:`, `outputs` (ADR-0084 D4). | **Flow** | ADR-0084 D2: ONE concept, three kinds. `kind: data` / `kind: ml` = `flows/*.yaml` with a `stages:` list (`FlowDef`); `agentic` = `flows/*.md` with BT frontmatter (a `TemplateSpec`). | **DataflowSpec / DataflowResult / ArtifactDescriptor** | what crosses the control-plane ↔ engine boundary: manifests and scalars, never rows (ADR-0081 D2/D3) | `dataflow/contract.py:179/254/226` | dataflow | engines, leg executor | yes | Engine |
| **DataflowEngine** | the runtime waist for flows: `validate / submit / poll / cancel / result`; selected by name from the environment (`[profile.backends]`) through `cairn.dataflow_engines` | `dataflow/engine.py:76`; `engine_registry.py:102 resolve_engine` | dataflow (protocol), cairn-operator-dataflow (impls: builtin, metaflow, skypilot, ssh) | leg executor, Temporal activities | yes (engine authors) | Runtime (≠) |
| **Runtime** | how a compiled agentic graph executes: `Runtime.invoke(compiled_graph, state, …)`; impls `InProcessRuntime`, `DBOSRuntime`, `TemporalRuntime`; chosen by `CAIRN_RUNTIME`/profile | `runtime/base.py:123`; `runtime/__init__.py:30 select_runtime`; `compiler.py:792 _resolve_runtime` | runtime | compiler | internal | Checkpointer |

| **Executor** (action sense) | write-side action with saga semantics in the legacy incident path (`ExecutorRegistry`, `ActionHandler`) | `cairn_platform/actions/executor.py`, `cairn_platform/actions/handler.py` (the platform, #2497; the protocol is `engine/runner.py` `ActionHandler`) | actions | Runner | internal | Action |
| **Operation / Operator** | the code unit: `Operation[I, O]` subclass with `input_schema`/`output_schema` (Pydantic), `run(inp, ctx)`, optional `mock`, `cancel`, `heartbeat`; class attrs `risk`, `executors`, `requires_approval`, `long_running`, `supports_*`, `reports`; registered with `@register_operator(name="pack/op")` | `operator/protocol.py:261`; `operator/registry.py:233` | operator substrate; implemented in operator packs | compiler (operation nodes), bridge (task legs), stages | **yes — the primary extension contract** | OperationContext, Binding |
| **OperationContext** | runtime services handed to `run`: `artifacts`, `secrets` (scoped), `metrics` (deprecated, ADR-0103), `cost`, `compute` (resolved connection), `report`, `logger`, heartbeat/cancel hooks | `operator/protocol.py:187` | operator substrate | operators | yes | Reporter |
| **Operation binding** | `operations/*.yaml` in a domain pack: which operator, input wiring (`$input`, `$state`, `$nodes`, `$env`…), approval, budget, resources | `operator/binding.py:131 OperationBinding` | operator substrate | compiler | yes | Expr |
| **Expr** | the ONE expression language (#1118): `$input.*`, `$steps.<id>.<field>`, `$config.*`, JMESPath predicates | `engine/expr.py:329 Expr`, `:465 compile_expr` | engine | pipeline planner, bridge, bindings | yes (authoring) | — |
| **Pack** | the distributable unit discovered via `cairn.packs`: name, version, asset dirs, descriptors (tools, executors, backends, capability bindings), settings inventory, doctor checks, manifest | `pack/protocol.py:124 Pack`; `pack/manifest.py:536 PackManifest` | pack system | registry aggregators (`all_*`) | yes | Manifest, Profile |

| **Capability** | an abstract name (`train.run`, `memory.search`, `redact.text`, `read_logs`) a template/pack requires and an operator/backend provides; bound per deployment | `pack/composition.py`, `core/registry.py:35 CapabilityRegistry`, `backends/protocol.py` | pack system | compiler, profile bindings | yes | Binding, Profile |
